## 保留风险

1. **上游权利真实性**：MIT 是上游公开给予的许可，不能独立证明每句文字、每段代码均不涉及他人权利；若收到具体权利线索，应核实并修正或移除相关内容。
2. **GPL 与商业解释**：组件 README 使用“非商业 GPLv3／商用购买授权”表述；标准 GPLv3 正文允许收费分发。保留两者出处，不把 README 表述擅自追加为 GPL 限制，也不据此替未来商业发行出具授权结论。闭源/商用前须明确授权路径，必要时咨询专业人士或替换组件。
3. **二进制分发**：将来发布 exe 时须另查 GPL/LGPL 对相应源码、许可证、修改/重新链接等义务，以及 wheel 内图标、字体、OCR 模型等素材。当前源码发布检查不覆盖它们。
4. **隐私与平台条款**：截图读取和向模型发送第三方聊天可能涉及隐私、个人信息处理和平台合同问题，取决于使用方式、授权和适用地区。开源许可不等于微信或相关参与者的许可。
5. **商标与人格权益**：上游、微信、模型品牌和资料中提到的人名仅用于来源或功能说明；不得在后续宣传中暗示授权、官方合作或真人代言。
6. **AI 输出**：生成内容存在错误、重复既有表达或不当建议的可能；不能把软件输出当成事实、专业服务或必然原创的作品。
