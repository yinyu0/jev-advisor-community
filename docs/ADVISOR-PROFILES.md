# 军师档案使用说明

2026-10-08：本地源码新增档案保存功能；之前生成的 0.1.0 安装包尚未更新。

## 使用

1. 退出旧程序，重新运行项目根目录的 `start-advisor.cmd`。
2. 在聊天软件打开单聊并采集消息，然后打开军师模式。
3. 第一次填写档案名称、关系、对方背景、共同经历和边界；在“我的资料”页填写共用的称呼、背景和偏好。资料均可留空，档案名称必填。
4. 说话风格仍在原来的软件设置里配置，没有增加第二份风格设置。
5. 点击“保存资料”只保存，不请求模型。勾选关联当前聊天后，下次会带出候选档案。
6. 检查当前聊天、档案和消息归属，再勾选确认，点击“保存并启用，生成回复”或“保存并深入分析”。启用后的新消息分析仍沿用原有行为，并可能产生 API 费用。
7. 同一会话持续启用时再次打开可沿用确认；编辑资料、选择其他档案或切换聊天后需要再次核对。

每个对象分别记住目标。关闭或切换档案遇到未保存编辑时，可选择保存、放弃或取消操作。“停用军师”保留已保存档案；“删除档案”会确认后永久删除该对象及其聊天关联，公共资料仍保留。

## 存储与边界

- 档案路径：`%LOCALAPPDATA%\JevAdvisorCommunity\advisor\profiles.dat`。
- 使用 Windows 当前用户 DPAPI 加密，临时写入文件也只包含密文；不保存聊天历史，不保存模型 API 密钥。
- 加密保护不能阻止同一 Windows 用户权限下运行的其他程序访问；不要将它当成独立密码保险库。换用户或换电脑不能保证直接解密，第一版不提供跨设备导入导出。
- 写入失败、损坏或其他程序同时修改时会明确报错，不静默覆盖原档案。
- 聊天关联由“平台＋OCR 标题”提供候选，不是可靠账号标识。同名、改名或识别有误时，必须人工检查并选择正确档案；不会自动合并对象。
- 请求模型时只提供已确认的当前对象资料及公共资料，档案名称、内部 ID 和其他对象资料不发给模型。
- 保存不产生模型请求；生成时增加的资料会占用输入 token。
- 档案位于应用数据目录，卸载程序默认保留。新版卸载脚本提供默认不勾选的“同时永久删除档案”选项；旧安装包仍使用旧脚本，不会删除新档案。

## 验证范围

使用临时目录与虚构资料验证 DPAPI 加密和重读、修改、删除隔离、写入失败、损坏保护、同名对象、确认状态、消息变化时拒绝过期分析及请求资料范围。没有读取真实聊天或进行付费模型调用。

卸载脚本已检查 PowerShell 语法，未对用户真实安装和档案执行卸载。
