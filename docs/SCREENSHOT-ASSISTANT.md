# 通用截图助手

2026-10-08：本地源码已实现。旧的 0.1.0 安装包尚未更新。

## 使用流程

1. 退出旧程序，双击项目根目录 `start-advisor.cmd`，点击主界面“截图助手 · 框选任意窗口聊天”。打开截图助手会暂停原有自动采集，不会在关闭后自动恢复。
2. 从下拉列表选择目标窗口，不限定 Soul、模拟器或聊天软件。窗口未出现可点击刷新；最小化窗口请先还原。
3. 点击“框选 / 重新框选”，在当前窗口快照上拖动鼠标圈定聊天区域，点击“使用此区域”。图片只在内存中处理，不保存。
4. 点击“识别聊天”，或按默认 Ctrl + Alt + K，重新截取最新画面并执行本地 OCR。快捷键可改为其他 Ctrl + Alt + 字母，J 留给原采集开关；当前运行中记住选择，关闭助手释放快捷键。
5. 检查文字和说话人。左右位置只是建议，不是可靠身份判断；“待标注”需要人工选择。可编辑、补充、删除、上下移动或合并连续同一说话人的行。
6. 默认使用当前会话最近 10 条非空消息，可调为 3～30 条。重复采集按完全一致的连续内容去重；文字修正后或 OCR 不一致时可能需要手动删除重复行。每个会话最多自动保留 200 条。
7. 如需军师，点击“选择 / 保存资料”，选择已有档案或创建并保存。点击“保存并使用此档案（不生成）”返回助手；保存和选择档案均不调用模型。普通回复无需建档。
8. 核对当前对象、所选资料与消息归属，勾选确认后点击“生成回复 / 重新生成”。软件使用原设置中的统一模型和说话风格；可能包含分析、起草、排序等多次请求。
9. 在输出区查看三条候选，自行调整并在目标软件输入发送。军师判断暂不回复时可能不返回候选，界面会显示建议。

## 会话与保存

- 切换聊天对象时，先在助手里切换或新建不同名称的会话。软件不会依据窗口标题自动认人，同一窗口可以显示多个对象。
- 当前运行中，各会话分别保留聊天和候选；切换后需重新确认。关闭助手窗口会暂停其操作并释放快捷键，重开可继续；退出整个程序清除临时聊天、候选及框选信息。
- 只有用户主动保存的人设资料使用现有 DPAPI 档案长期保存，详见 ADVISOR-PROFILES.md。默认会话名只是占位名称，请为不同对象使用清楚的名称并核对档案。
- 框选区域按窗口像素记录，移动窗口不要求重新框选。下一次采集时若尺寸、DPI 或截图尺寸变化，会要求重新框选；布局变化但尺寸不变需要用户主动重新框选。
- 更换目标窗口会清除框选，但不会自动判断是否更换对象；需要用户核对会话。
- 生成失败时保留编辑文字，由用户主动重试；不自动重试整条生成流程。尚未结束的模型请求无法撤回计费，切换对象或编辑后其结果会被丢弃。

## 验证与限制

已通过单元／集成测试、离屏界面检查，以及对程序自建虚构聊天窗口的真实 Windows Graphics Capture 截图与本地 OCR 测试。测试没有读取真实聊天，也没有调用付费模型。

未对所有模拟器、聊天软件、受保护窗口或主题进行兼容性验证。黑屏、无文字或无法截图会给出提示；某些旧画面或布局异常无法自动判定，始终需要人工核对。第一版只处理单聊文字，不自动翻页、不理解语音或图片语义、不填入或发送。

## 开发验证

- `python -m unittest discover -s tests`：模拟数据测试，不联网生成。
- `python tools/screenshot_demo.py`：虚构界面预览，不采集真实窗口，不读实际档案。
- `python tools/screenshot_demo.py --capture-smoke`：只截取脚本自己创建的测试窗口，执行真实截图与 OCR，不保存截图。
